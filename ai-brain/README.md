# ai-brain

Project knowledge base for this repo, written for whichever AI assistant (or human) picks up work here next. Read `context.md` and `rules.md` first — they're the highest-leverage files. Everything else is depth on demand.

## Index

- **[context.md](context.md)** — what this project is, who it's for, tech stack, architecture.
- **[identity.md](identity.md)** — the design system (colors, type, tone) and how to apply it.
- **[rules.md](rules.md)** — concrete dos/don'ts distilled from real feedback on this project. Read before touching styling.
- **[playbook.md](playbook.md)** — how to actually work in this repo: verification loop, sample-data workflow, common gotchas.
- **[project-history.md](project-history.md)** — chronological log of major decisions and why they were made.
- **[skills/](skills/)** — task-specific playbooks (code generation, code review, debugging, SEO, worked examples).

## Why this exists

This repo went through a long iterative design-feedback loop (hundreds of small, specific UI change requests). A lot of hard-won context — decisions that were made, reverted, and re-made; conventions that only became clear after several rounds of correction — would otherwise be lost between sessions. This folder is that memory.
